# W.A.T.O.M. 1240 AM — On-Air Updates

Public, read-only distribution for the **W.A.T.O.M. Atomic Frontier Radio** personal app. Android devices can fetch approved programming updates without signing into GitHub.

**Important boundaries:** This repository is intentionally separate from the private WATOM-Android source and music collections. Publish only original W.A.T.O.M. announcer recordings, original civil-defense features, approved original jingles, original sponsor spots, original Jack-narrated folklore tales and their teasers, dated weather/news scripts and small update manifests. Do **not** upload third-party music, radio-drama episodes, Google Drive originals, account credentials, private GitHub tokens, or proprietary source.

`weekly-releases/current.json` is the latest approved broadcast schedule. A valid release may reference only already-installed songs for rotation and separately approved original short clips. New files are uploaded and quality-checked before the pointer is updated. Android verifies their lengths and SHA-256 hashes before activating them.

This is public content: anyone may access these short original broadcast updates. The private music and radio-show library remains private.

The November 8 release adds an original Jack-narrated Saturday Strange Tales episode. The private APK maintains ownership and playback of all user-provided music and outside radio shows; this public feed contains only original W.A.T.O.M. commissioned narration and metadata. MP3 story clips may be up to 8 MB with separate SHA-256 and editorial checks; ordinary clips stay under 900 KB.
